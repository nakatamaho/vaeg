PC-9801B3-E02 on the PC-88VA - probes B0 to B4c (vaeg M148)

Boot this disk in V3 mode on the PC-88VA. Keep it write-enabled:
every program appends its lines to A:\B3LOG.TXT. If a photograph and
the log disagree, the log is right. Run the stages in order and stop
at the first that does not pass.

B3E0   stage B0, board NOT installed (also on a VA2/VA3).
       Read only. PASS = every B3-E02 port reads FF.
       Optional: run it once more with the board installed (no write).
B0.5   with a tester: slot pins A20-A23 at the MS-DOS prompt.
B3E1   stage B1, board installed, VA only. Board control 0FA2h/0FA3h.
       PASS = ID 60h and every index read back.
B3E2   stage B2. Wake-up (0904h/0902h), CR27, SR06 lock.
       PASS = CR27 98h-9Bh (CL-GD5428), SR06 12h/0Fh.
       Options set board reg 03h before the wake-up and restore it:
       /MMIO bit 0 (memory-mapped I/O), /RELAY bit 1 (relay: the
       board's video output). The earlier probes wrote 03h (both).
       If plain B3E2 fails, try in this order:
         B3E2 /MMIO      B3E2 /RELAY      B3E2 /MMIO /RELAY
B3E3   stage B3. Register snapshot SR00-1F, GR00-3F, CR00-3F.
       Give it the options with which B3E2 passed.
B3E4   stage B4a. VRAM windows that cannot overlap main RAM:
       W1 board window 0B0000h (reg 01h = 10h) at B0000h, W2 the
       chip's VGA window at A0000h. Sets reg 03h bit 0 itself.
       PASS = both banks (GR09 00h/10h) read back.
B3E5   stage B4b. The bank RAM path: OUT 1D0h,n (n=01h-FFh) sends
       80000h-9FFFFh to the slot. Sweeps every bank with board
       windows off / F60000h / 0B0000h and pattern-tests the banks
       that change. Banks that answer without the window (another
       board's RAM) are listed and never written.
B3E6   stage B4c. Does the board see the VA's memory cycles at all?
       Fills VRAM by BLT and checks the VGA latch (CR22) after a CPU
       read through each candidate window. Also scans the 4KB blocks
       below 1MB (C0000h-E7FFFh) for reg 01h = 40h-67h. Note reg04:
       bit 4 = 1 is the board's 15MB mode (DIP switch); running B3E6
       in both DIP modes is useful.

Exit codes (ERRORLEVEL): 0 pass, 1 option, 2 machine, 3 no board,
4 log not written, 10h and up: stage failure (see the SUM line).
Port values: FF = undriven, D:xx = driven xx, F:... = six differing
reads (floating bus).

Only B3E6 writes main RAM: one byte, saved and restored with interrupts
off. Only B3E4-B3E6 write the board VRAM and the window register
(inside their tests); only /RELAY writes the relay bit. Everything written is restored or undone.
