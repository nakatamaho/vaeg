## Presenter automation

Target: Linux x86_64 host, Xvfb 1280x1024 at 96 dpi with Openbox, SDL x11
(a virtual-X11 software-integration target). The runtime-speed and matrix
selftests pass. Runtime speed: capture exit 0, ten cases; an unvalidated
visual inspection of the F11 case showed 1.50x (about 12.01 MHz
equivalent) with the configured 7.9872 MHz CPU unchanged; the fast-forward
rate depends on host load and is not a contract. Layout: the DRAFT
reference set prepared from the first capture (manifest SHA-256
`5c49a43069408be73cb963be182c5bca9879c8c598a123c1d3a659997e5b3ba4`) matches
the second **32/32**; approval remains the maintainer's decision.

The campaign script ended with exit 144 after all captures because its final
`pkill -f` matched its own command line; every check above had completed
and printed its result first. The CTest run that was to follow was started
separately (see the task file).
