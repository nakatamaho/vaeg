## Result at this checkpoint

The real recorder backend writes a complete seekable FFV1/PCM movie from synthetic slices.

## Bounded implementation instructions

1. Implement exclusive local seekable output ownership, a partial-file lifecycle and non-replacing final publication. Reuse approved path/handle helpers or add a narrow tested AVIO file sink.

2. Create both streams and write the header before packets. Capture actual post-header time bases, keep codec and stream timestamps distinct and preserve common-epoch offsets.

3. Interleave complete-slice video and audio through the production worker. Flush both encoders, write trailer/cues and check write/seek/flush/close/publication errors.

4. Add a ROM-free fixture executable using production recording APIs; generate independent expected RGB/PCM and a small JSON timing manifest out of tree.

5. Add tools/recording/verify_movie.py or an equivalent established validator to decode/probe the file and compare actual pixels/samples/order/PTS. Keep negative content checks independent of Git history.

6. Exercise multiple aligned flash/impulse markers and normal Stop at a known frame limit. Document actual container quantization instead of expecting exact rational timestamps in MKV.
